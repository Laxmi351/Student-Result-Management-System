
# Student Result Management System

## Project Description
Student Result Management System is a Java-based web application that manages student details, subject-wise marks and academic results.

The system automatically calculates total marks, percentage, grades and pass/fail status.

## Features
- Add new student records
- Display all student records
- Search students by roll number
- Store subject-wise marks
- Calculate total marks and percentage
- Automatically assign grades
- Display Pass/Fail status
- View and print student marksheets
- Validate student details and marks
- Store records using file handling

## Installation and Setup

1. Install Java JDK 17 or later.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command on Windows:

   `.\run.bat`

6. Open your browser and visit:

   `http://localhost:8080`

## Data Storage
Student records are stored locally in the `data/students.tsv` file.

No MySQL database is required.
